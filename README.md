# Post-Correspondence-Problem-of-sushi

ポスト対応問題を体験できるブラウザゲームです。

## 画面構成

- タイトル画面
  - ゲームモード選択
    - NP-ハードモードへの遷移ボタン
    - 決定不能モードへの遷移ボタン
- NP-ハードモード問題選択画面
  - グリッド上に配置される問題番号
- 問題画面
  - ポスト問題のタイルに対応するボタン（刺身パック＆タンポポのベルトコンベア風UI）
  - 決定不能モードのみ不可能ボタンが追加される
  - 生成された文字列×2の表示エリア
  - 戻るボタン
  - すべて消去するとクリア画面に遷移
- クリア画面
  - 次の問題へ
  - ホームに戻る

## 開発・実行

```bash
npm install
npm run dev
```

## 技術構成

- Vite + React + TypeScript
- Tailwind CSS
## 追加問題の出典

問題13〜17は [Mojashi/pcp-3-4-proofs](https://github.com/Mojashi/pcp-3-4-proofs) の `solvable.thy` に掲載された解答可能インスタンスです。
参照コミット: `b0c27507646a4f0acfee555948b5d09d26c5e6cc`。

| 問題 | 元のインスタンス（各組は上段_下段） | 公開解答の手数 | ゲーム内の解答手数 |
| --- | --- | ---: | ---: |
| 13 | `1110_1__1_0__0_1110` | 153 | 152 |
| 14 | `1101_1__1_101__0_011` | 175 | 174 |
| 15 | `1001_1__10_0__0_100` | 452 | 451 |
| 16 | `1101_1__1_10__0_1011` | 1584 | 1583 |
| 17 | `1110_0__10_1__1_1011` | 2712 | 2711 |

手数は掲載された解答の長さであり、最短手数を保証するものではありません。
上段は `0 → S（刺身）、1 → T（タンポポ）`、下段は `0 → T、1 → S` に変換しています。
空の初期配置による即時クリアを避けるため、公開解答の最初の1手を置いて消去した残りを初期配置とし、残りの手順を解答として保存しています。

データの再生成（ネット接続が必要）と、ゲームの実際のクリア判定による検証:

```bash
node scripts/import-pcp-proofs.mjs
node scripts/verify-pcp-proofs.mjs
```
